# Aexquisitely Website

Website statis untuk profil musik Aexquisitely / Rizik Hadi Gundono.

## Struktur proyek

```text
Si-Om/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js
```

## Menjalankan secara lokal

Buka `index.html` di browser. Koneksi internet diperlukan untuk memuat Google Fonts serta embed Spotify dan YouTube.

## Deploy ke GitHub Pages

1. Buka **Settings → Pages** pada repository.
2. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
4. Tunggu proses deployment selesai. GitHub akan menampilkan URL website di bagian Pages.
